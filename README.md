# Polymarket Copy-Trading Bot

Automatically mirrors the trades of a profitable Polymarket user ([surfandturf](https://polymarket.com)) using a tiered bet-sizing strategy. Supports paper trading, live execution, a web dashboard, and Telegram notifications.

## How it works

1. **Monitor** — polls surfandturf's trade activity every 20 seconds via Polymarket's data API
2. **Detect** — filters for `BUY`, `SELL`, and `REDEEM` events
3. **Size** — looks up surfandturf's total position value in the market and applies tiered sizing (see Configuration)
4. **Risk check** — enforces per-position, total exposure, and daily loss limits before every order
5. **Execute** — places a market (FOK) or limit (GTC) order via Polymarket's CLOB API
6. **Track** — records positions and P&L in a local SQLite database
7. **Notify** — sends Telegram messages on every trade event and a daily portfolio summary

## Prerequisites

- Python 3.11+
- A Polymarket account funded with USDC on Polygon (live trading only)

## Setup

**1. Clone and install dependencies**
```bash
git clone https://github.com/Rampex1/Polymarket.git
cd Polymarket
bash run.sh
```

`run.sh` creates a virtual environment, installs dependencies, and starts the bot automatically.

**2. Configure environment variables**

Copy `.env.example` to `.env` and fill in the values:

```
TARGET_ADDRESS=0x...       # surfandturf's wallet (from their Polymarket profile URL)
PAPER_TRADE=true           # set to false for live trading
POLY_PRIVATE_KEY=0x...     # your wallet private key (live trading only)
POLY_FUNDER_ADDRESS=0x...  # your proxy wallet address (live trading only)
POLY_API_KEY=...           # generated by scripts/setup_keys.py
POLY_API_SECRET=...
POLY_API_PASSPHRASE=...
```

## Running

**Paper trade (safe default)**
```bash
source .venv/bin/activate
```

**Web dashboard**
```bash
source .venv/bin/activate
```

## Configuration

All values can be overridden in `.env`.

| Variable | Default | Description |
|---|---|---|
| `TARGET_ADDRESS` | — | Wallet address to copy |
| `PAPER_TRADE` | `true` | Log-only mode; set to `false` for live trading |
| `PAPER_STARTING_BALANCE` | `10000.0` | Virtual USDC balance for paper trading |
| `TIER1_MIN` | `80000` | Min target holding to place a bet |
| `TIER1_MAX` | `150000` | Upper bound of tier 1 ($1 bet) |
| `TIER1_SIZE` | `1.0` | Bet size when target holding is in tier 1 |
| `TIER2_MAX` | `500000` | Upper bound of tier 2 ($2 bet) |
| `TIER2_SIZE` | `2.0` | Bet size when target holding is above tier 1 |
| `MIN_ORDER_SIZE_USDC` | `1.0` | Skip if order is below this floor (Polymarket minimum) |
| `MAX_POSITION_SIZE_USDC` | `2.0` | Max USDC cost per market position |
| `MAX_TOTAL_EXPOSURE_USDC` | `12.0` | Max total USDC across all open positions |
| `DAILY_LOSS_LIMIT_USDC` | `4.0` | Stop new buys if today's realized loss exceeds this |
| `MAX_SLIPPAGE` | `0.05` | Skip trade if price moved more than 5% since signal |
| `ORDER_TYPE` | `market` | `market` (FOK) or `limit` (GTC at signal price) |
| `TELEGRAM_BOT_TOKEN` | — | From [@BotFather](https://t.me/BotFather) |
| `TELEGRAM_CHAT_ID` | — | Your Telegram chat ID |
| `POLL_INTERVAL_SECONDS` | `20` | How often to check for new trades |

## Telegram notifications

1. Message [@BotFather](https://t.me/BotFather) on Telegram → `/newbot` → copy the token
2. Start a chat with your new bot
3. Visit `https://api.telegram.org/bot<TOKEN>/getUpdates` to find your `chat_id`
4. Add both to `.env`

## Deploying on a VPS

```bash
# Copy the repo to your server, then:
cp .env.example .env   # fill in all values
docker compose up -d   # build and start
docker compose logs -f # tail logs
```

`positions.db` is bind-mounted from the host so trade history survives container rebuilds.
